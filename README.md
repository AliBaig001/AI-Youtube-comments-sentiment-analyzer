## 🧠 AI YouTube Comments Sentiment Analyzer

This project uses Natural Language Processing (NLP) to analyze the sentiment of comments from YouTube videos. It helps identify whether user feedback is **positive**, **negative**, or **neutral** perfect for content creators, marketers, or researchers.

### 🚀 Features
- Extracts comments from YouTube videos
- Performs sentiment analysis using NLP models
- Visualizes sentiment distribution
- Supports multilingual input (customizable)

### 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Hugging Face Transformers (optional)
- Google API (for YouTube comment extraction)

### 📦 Installation
```bash
git clone https://github.com/AliBaig001/AI-Youtube-comments-sentiment-analyzer.git
cd AI-Youtube-comments-sentiment-analyzer
pip install -r requirements.txt
```

### 📈 How to Use
1. Open the Jupyter Notebook, run the code
2. Paste the YouTube video URL.
3. Run the cells to extract and analyze comments.
4. View sentiment results in charts.
